# serde_yml — Deprecated

[![Crates.io][crates-badge]][07] [![Docs.rs][docs-badge]][08] [![Migration][migration-badge]][13]

⚠️ **This crate is unmaintained.** The `0.0.13` release is a thin
compatibility shim that forwards every call to a maintained,
pure-Rust YAML backend so existing call sites keep working while
you migrate to a maintained alternative of your choice.

- [`README.md`][06] — overview, install, migration paths
- [`MIGRATION.md`][13] — full mapping tables per destination crate
- [`SECURITY.md`][14] — RUSTSEC-2025-0068 status (fixed in 0.0.13)
